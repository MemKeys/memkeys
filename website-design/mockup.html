How it works

Keyed first. Graph and vector are derived views.

Agents store facts by attribute into one keyed core. The graph and the vector index are views computed on top of those facts — not separate stores you keep in sync.

Keyed coreFacts addressed by project, issue, run, agent — each with a validity window.
Graph viewTraverse relationships between keyed facts in a single hop.
Vector viewSemantic search for when you don't yet know the key.
