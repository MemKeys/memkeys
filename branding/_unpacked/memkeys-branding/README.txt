MemKeys — Brand Package
=======================
Final mark: "The Address" — M3 gradient @ with keyhole center (ISI-5828).
Palette: gradient ring #17356F -> #3E6FD9 · golden keyhole #F7C948 · dark ground #0B1830.

WHAT GOES WHERE (GitHub org)
----------------------------
- Org / profile avatar ....... kit/memkeys-avatar-light-512.png  (or -dark-512 on dark themes)
- Repo "Social preview" ...... kit/memkeys-social-github-1280x640.png   (Settings > General > Social preview)
- Favicon (docs site) ........ kit/favicon.ico  (+ kit/favicon.svg for modern browsers)
- README / banner mark ....... kit/memkeys-mark-256.png or 512.png (transparent)
- Dark READMEs ............... kit/memkeys-mark-reverse-512.png (light ink, transparent)

CONTENTS
--------
mark/     master SVGs (primary, mono, reverse) — scalable source of truth
kit/      PNG ladder 16-512, favicon.ico/.svg, mono/reverse/on-dark, avatars, OG + GitHub social, address-kit-rev3.pdf
lockups/  wordmark lockups (horizontal + stacked; colour/mono/reverse) + sheet
docs/     BRAND-CONCEPTS.md (rationale + collision check), BRAND-WORDMARK.md

All vectors regenerate from the scripts in the repo's branding/ dir.
Mark is wordmark-free; wordmark uses IBM Plex Sans Bold (see docs/BRAND-WORDMARK.md).
